# relation-app-practice

## 概要
COACHTECH 教材 Tutorial 9-5「リレーション ハンズオン演習」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Eloquent ORM（hasMany / belongsTo / belongsToMany）
- MySQL

## 学んだこと
- モデルとマイグレーションを作成する
- リレーションを定義する
- コントローラーでEager Loadingとタグ絞り込みを実装する
- ルーティングを設定する
